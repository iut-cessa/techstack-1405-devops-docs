در هفته‌ی دوم، Linux را از دید کسی یاد می‌گیریم که قرار است سرویس‌ها و زیرساخت را اداره کند. هدف، حفظ‌کردن همه‌ی دستورها نیست؛ باید بتوانید مستندات را بخوانید، وضعیت سیستم را بررسی کنید و کارهای تکراری را با اطمینان انجام دهید.

اهداف این هفته:

- **محیط آزمایشی Ubuntu Server** — نصب در VirtualBox و اتصال SSH (اختیاری)
- **محیط Linux و CLI** — ترمینال، مسیرها و کار با فایل‌ها و دایرکتوری‌ها
- **جست‌وجو و پردازش متن** — کار با Pipe، Redirection، `grep` و `find`
- **ساختار و دسترسی سیستم** — FHS، کاربران، گروه‌ها، مجوزها و Package Manager
- **عملیات سرویس و عیب‌یابی** — فرایند(Process)ها، `systemd` و لاگ‌های `journalctl`
- **خودکارسازی مقدماتی** — اسکریپت‌های Bash و زمان‌بندی برای کارهای تکراری

راهنمای نخست از Ubuntu Server در VirtualBox استفاده می‌کند. مثال‌ها برای توزیع‌های رایج Linux نیز نوشته شده‌اند؛ اگر از Debian یا Ubuntu استفاده می‌کنید، دستورهای `apt` و اگر از Fedora یا RHEL استفاده می‌کنید، دستورهای `dnf` را دنبال کنید.
